- java-version.txt, mvn-version.txt: ашигласан орчны хувилбар.
- mvn-test.txt: сэргээсэн source дээрх эцсийн тест.
- mvn-test-mutant-1.txt: inactive-student шалгалт авсан туршилт.
- mvn-test-mutant-2.txt: saveRegistration дуудалт авсан туршилт.
- mvn-test-mutant-3.txt: courseId null шалгалт авсан туршилт.
- mvn-test-clean-clone.txt: clean clone дотор дахин ажиллуулсан тест.

Эдгээр логийг зөвхөн Maven-ийг бодитоор ажиллуулсны дараа хадгална.
